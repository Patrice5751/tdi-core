# TDI Experimental Protocol

Version: 1.0

---

# Purpose

The purpose of this protocol is to continuously improve TDI using objective evidence collected from real trading activity.

Every analysed trade becomes an observation.

Every new rule becomes a hypothesis.

Every software version becomes an experiment.

---

# Scientific Principles

TDI follows a continuous improvement cycle.

Hypothesis

↓

Implementation

↓

Real Trading

↓

Measurement

↓

Validation

↓

Improvement

No rule is accepted solely because it appears logical.

Every rule must ultimately demonstrate measurable value.

---

# Experimental Unit

One analysed trade = one observation.

The outcome of a single trade never validates or invalidates a rule.

Only statistical evidence can do so.

---

# Data Collection

For every analysed trade TDI stores:

Trade Setup

Market Context

Decision

Rule Results

Score

Recommendation

Trade Outcome

Trader Comments

Software Version

---

# Primary KPI

The primary performance indicator of TDI is:

Expectancy (R per trade)

---

# Secondary KPIs

Win Rate

Profit Factor

Average Winner

Average Loser

Maximum Drawdown

Average Score

Recommendation Accuracy

---

# Rule Validation

Each rule progresses through four states.

Experimental

↓

Observed

↓

Validated

↓

Optimized

A rule may also become:

Deprecated

if it no longer improves trading performance.

---

# Version Validation

A new version of TDI must be evaluated on a statistically meaningful sample before replacing the previous one.

Version comparison includes:

Expectancy

Profit Factor

Drawdown

Recommendation Accuracy

---

# Golden Rule

Never modify TDI because of one trade.

Modify TDI only because objective statistics justify the change.

---

# Mission

Improve trading performance by improving trading decisions.

Measure.

Explain.

Improve.
